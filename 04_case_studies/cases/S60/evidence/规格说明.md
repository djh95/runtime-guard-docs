# S60 — PD 类 post-prefill 中段槽污染（金标 A 教学钉）

| 字段 | 值 |
|------|-----|
| **ID** | S60 |
| **Origin** | 构造匹配 PD/传输污染类（post-prefill 单槽污染）；非 Mooncake 真 1P1D |
| **Priority** | P0（定界深度教学） |
| **构造预期：根因是否在 KV** | 是（cache 槽在 prefill 写完后被污染） |
| **Guard pin** | G2 `f2aefd068` + 抓 dump 时临时合入 [#19285](https://github.com/vllm-project/vllm-ascend/pull/19285) |
| **复现方式** | `origin` 类软注入（槽位取反；无 NaN/fill） |
| **difficulty** | `medium` |

## Origin 说明

定界金标 A（用户例）：prompt 中段某 token KV 余弦≈0，其后多个 prompt 又≈1；out[0] 再坏且低层起偏低；仅 PD 路径复现。

本包用 **post-prefill / 首 decode 步** 对 **prompt 中段槽（默认 mid=5）** 做 K/V 符号取反，模拟「写对了、交接/传输后写歪」的 PD 类时序。  
**对照：** 无 overlay 的清洁树不注入 → 不复现该链。真 Mooncake 1P1D 未在本钉点拓扑跑通（HCCN/双机未开）；文档不写假「已真 PD」。

## Overlay

[`overlay.patch`](./overlay.patch) · 生成器 `gen_s60_overlay.py`（同批 evidence）。

## Trigger / knobs / forbidden

1. **Trigger：** `ANOMALY_TRIGGER S60 pd_mid_slot_pollute`
2. **Allowed knobs：** Qwen3-8B TP2；并发；`S60_MID`（默认 5）
3. **Forbidden：** force-NaN；token `fill_`；伪造仅 PD 文案却无对照

## 模型

`Qwen3-8B` · TP2。

## Expected detector

`token_repeat`（本环境基线对部分 prompt 也有复读噪声；定界以 KV 表为准）。
