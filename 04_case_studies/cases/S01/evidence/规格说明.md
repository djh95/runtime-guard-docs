## Overlay

包内 [`overlay.patch`](./overlay.patch)（自 test `01_kv_block_nonzero/patches/` 拷入）。强制 `needs_kv_cache_zeroing`、skip `zero_block_ids`；dense 路径可含 synth_block0（抬高 trigger 日志 ≠ 已读到脏 KV 乱码）。

## 复现技巧 / knobs

1. Overlay 生效后起服：TP≥2，禁 APC / prefix cache。
2. **形态前提：hybrid / 量化 KV**；稠密 bf16 上本 pin 实测无目标坏输出（见 README 结案）。
3. 冷启动后打满短 prompt 突发，促使新 block 分配。
4. **禁止**：force-write NaN / token-fill 伪造症状。

## 期望 detector

- 有目标坏输出时：乱码类 / `logits_finite`（视形态）
