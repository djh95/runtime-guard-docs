# 词汇表（短）

只收**多页稳定出现、又不好用一句话白话替换**的词。其它说法在出现处写口语即可，不必查表。

| 词 | 含义 |
|----|------|
| **keep-set** | 本仓对外保留的典型异常案例集（约 15 个 `cases/Sxx/`）。 |
| **overlay** | 两义勿混：① 案例里的 **`overlay.patch`**＝叠在干净产品树上的**故障补丁**；② 启服里的 **`runtime_config` 字典**＝启动时合并进默认配置的**配置覆盖**（不是打故障）。 |
| **三层率** | **trigger**（注入路径打中）/ **precision**（输出已见异常，≠模型精度）/ **detect**（Guard 报告命中）。三者分开记，不相等。 |
| **清洁标杆 / ref** | **未打故障补丁**的对照服务，或其 KV dump；和异常侧（buggy）对账用。 |
| **Guard pin** | 实验钉死的 Runtime Guard / 产品树 git 提交（常见写作 G2 + `f2aefd068…`，跑批里常作 `wt_sha`）。不是硬件 pin。 |
| **force-feed** | 按报告里的 **token id 原样**喂给干净服务（禁止把字符串再 tokenize），用来抓同序列的标杆 KV。 |
