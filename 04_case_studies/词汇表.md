# 词汇表（短）

只收**多页稳定出现、又不好用一句话白话替换**的词（约十来个）。其它说法在出现处写口语即可，不必查表。结案四档、检测辅标、怎么复现 → [本目录 README](./README.md)。启服配置 → [01](../01_enable_and_start/README.md)。定界十问 → [02](../02_problem_localization/README.md)。

| 词 | 含义 |
|----|------|
| **keep-set** | 本仓对外保留的典型异常案例集（约 15 个 `cases/Sxx/`）。 |
| **overlay** | 两义勿混：① 案例里的 **`overlay.patch`**＝叠在干净产品树上的**故障补丁**；② 启服里的 **`runtime_config` 字典**＝启动时合并进默认配置的**配置覆盖**（不是打故障）。 |
| **三层率** | **trigger**（`ANOMALY_TRIGGER` 等**路径开火事件**次数，可＞请求数）/ **precision**（输出已见异常的请求数口径，≠模型精度）/ **detect**（Guard `report_*.json` 份数）。三者分开记，不相等；**勿**把 trigger 当成「打中的请求数」。 |
| **清洁标杆 / ref** | **未打故障补丁**的对照服务，或其 KV dump；和异常侧（buggy）对账用。 |
| **Guard pin** | 实验钉死的 Runtime Guard / 产品树 git 提交（常见写作 G2 + `f2aefd068…`，跑批里常作 `wt_sha`）。不是硬件 pin。 |
| **force-feed** | 按报告里的 **token id 原样**喂给干净服务（禁止把字符串再 tokenize），用来抓同序列的标杆 KV。 |
| **数值问题** | 对异常 KV 与清洁标杆做对比时，**先检查有效槽里的数本身是否合法**；若属于下列任一类，该（token, 层）格标为「数值问题」并写出细分类型，**不算余弦相似度**。只有两边都是有限、可用的向量时，才比「像不像」。常见细分：**全零**（有效槽几乎全是 0）、**范数 0**（向量长度为 0，余弦无意义）、**NaN**（不是数）、**Inf / -Inf**（溢出正负无穷）。表里不要只写笼统「数值异常」，要写清是哪一种。说法上：**先查数值问题，再比相似度**；「无数值问题」= 有效槽未发现上述几类（勿写成「无数问题」，易被误读成「很多问题」）。 |
| **对账** | 把异常侧 KV dump 和清洁标杆 dump **逐项核对**（形状、数值问题、相似度等），看两边是否一致。 |
| **有效槽 / 未用槽** | dump 是整块 cache：**有效槽**＝本请求真正写过、对比要用的 token 位置；**未用槽**＝块里还没写到的位置。未用多数为 0，偶见有限非零残留（卫生脏写，通常不单独定「结果由此坏」）；亦可有 NaN/Inf（严重）。对比前先屏蔽未用槽；**勿写「未用一定填 0」**。 |
| **结案四档** | keep-set 总评只用这四档：① 未复现 ② 复现未抓到有效异常 KV ③ KV 一致→排除 KV ④ KV 不一致→按十问定界。检测另写「检出 / 漏检」等，不用 PASS/FAIL 当整案总评。 |
| **钉点同跑 / 只钉一轮** | 报告、dump、三层数字、表和结论文字必须来自**同一次请求、同一轮验证跑批**；重跑就整包替换，禁止拿别的目录或旧 req 补表改结案。 |
| **两对同向** | 至少两对「异常↔标杆」对比得出**同一方向**的结论（都匹配，或都在相近位置分叉）。一对分叉、一对干净 → 写「非两组同向」，勿揉成假同向。 |
| **必现** | 在已验证的输入/配置下，异常**稳定反复出现**（连测多轮仍坏）。看似每次都坏 ≠ 已证实必现，见 [02 Step 0.5](../02_problem_localization/README.md)。 |
| **弱窗** | 对比窗口证据偏弱：例如 dump 时几乎只生成 1 个 token、主要只覆盖 prompt，或 completion 不是目标异常形态——可做数值检查，但不宜强做层定位。 |
| **叠打** | 两个适配补丁包（如 `05_mrv1` 与 `05_v030`）**不能同时打**到同一棵树上。 |
| **manual_dump 水位** | 配置里 `dump.manual_dump = N` 是**目标总次数**（不是「还剩几次」）；进程在内存里计数，≥N 就停。要继续抓需把 N 调大（水位升高）。 |

其它常在正文首次出现时用括号带过的词（不进表）：格＝某一个 token × 某一层；dump 双名＝同一层两套文件名（如 `layer_27` ↔ `model.layers.0`）；接线包＝把 Guard 接到某 release 的适配补丁包；殿后＝放到最后再做。
